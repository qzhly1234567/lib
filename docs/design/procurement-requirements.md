# 厂家与设备信息 · 设计需求

用户已明确授权按设计稿实施。本地业务改造已完成，尚未提交、推送或部署。

## 已确认

- 普通页面顶部两个菜单：询价厂家信息、设备信息。
- 厂家筛选：系统、设备名称、品牌（供货厂家）、联系人、联系电话。
- 厂家列表：序号、上述五项、备注。列表与过滤器中间右侧按钮“添加询价厂家”。
- 厂家表单：上述五项必填，备注选填。独立页面视图。
- 设备列表：序号、设备分类、设备名称、规格/参数、材质、购置单价（元）、备注。
- 设备表单：设备分类和设备名称必填，其余选填。流程同厂家。
- 筛选按模糊匹配执行；设计按多个条件 AND 组合，查询按钮触发，一键重置。
- 两种新增提交后弹出成功提示，提供“返回列表”“继续添加”；前者返回列表，后者清空表单。
- 后台独立地址、无密码、与普通页没有互跳入口，支持两表增删改查。编辑用独立表单视图，删除二次确认。
- 沿用日夜主题、无纸鹤品牌文案。

## 设计采用的常规细节

- 设备筛选不包含序号与备注，购置单价按输入文本模糊匹配；金额录入限制非负、两位小数。
- 返回列表清除筛选，便于看到新记录。
- 模拟数据保存在内存，刷新恢复，不发出任何业务 API 请求。
- 普通稿 procurement-design.html，后台稿 procurement-admin-design.html；通过 hash 切换实体及列表/添加/编辑视图。

## 验证记录

- 两份 HTML 的 JavaScript 语法检查通过。
- 浏览器验证：厂家模糊筛选；厂家提交成功及“继续添加”清空；设备只填写必填字段提交及“返回列表”；后台厂家编辑和删除二次确认。
