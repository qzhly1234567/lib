# SeaTable 两表配置清单

在现有 Base 内创建以下两张表，表名与列名必须完全一致。不要删除旧“信息登记”表，也不要将其姓名/电话数据直接覆盖到新字段。

## 询价厂家信息

| 列名 | SeaTable 类型 | 页面必填 |
| --- | --- | --- |
| 系统 | 文本 | 是 |
| 设备名称 | 文本 | 是 |
| 品牌（供货厂家） | 文本 | 是 |
| 联系人 | 文本 | 是 |
| 联系电话 | 文本 | 是 |
| 备注 | 文本或长文本 | 否 |

电话保持文本，以保留前导零、加号和分机。

## 设备信息

| 列名 | SeaTable 类型 | 页面必填 |
| --- | --- | --- |
| 设备分类 | 文本 | 是 |
| 设备类别 | 文本 | 否 |
| 设备名称 | 文本 | 是 |
| 规格/参数 | 文本 | 否 |
| 材质 | 文本 | 否 |
| 购置单价（元） | **数字**，建议显示两位小数 | 否 |
| 备注 | 文本或长文本 | 否 |

第一列可以直接命名为“系统”或“设备分类”，也可保留其他列。额外列不会展示到网页。序号由页面生成，不需要在 SeaTable 建序号列。

金额输入校验为非负、最多两位小数且小于 1 万亿元；零元保存为数字 0，留空保存为空值。若由文本列转数字列，请先检查已有内容是否可以转换，必要时在 SeaTable 备份后转换，程序不自动修改列结构或迁移旧数据。

## 本次只读核对结果（2026-10-29）

用户已建立两表。核对时发现：

1. “设备信息”的“购置单价（元）”仍为文本列，需要改为数字。
2. “询价厂家信息”缺少“备注”，需要添加文本或长文本列。

代码会在查询/写入前检查这些字段和类型；结构不符合时返回明确错误，不静默丢弃数据。更改结构后，热实例最多约 60 秒更新元数据缓存。

## 下拉选项子表

- `设备分类` 表：`名称` 文本列，供设备信息的“设备分类”表单下拉选择。
- `系统` 表：`名称` 文本列，供询价厂家信息的“系统”表单下拉选择。

普通新增与后台新增/编辑每次进入表单时，通过同域 API 的 options 动作读取对应子表。后端只返回非空、去重的名称，保留 SeaTable 行顺序，不返回子表内部字段。维护选项无需修改代码，重新打开表单即可读取最新内容。

主表字段保持文本类型，保存选中的名称，不是 SeaTable 链接列。查询区同样使用下拉，其他条件保留模糊文本搜索。编辑时如果原名称已从子表移除，会显示“历史值”，保留原内容，避免静默清空。子表为空时不提供示例项，读取失败则禁用提交并允许重试。

- 最新查询交互：系统、设备分类使用真实子表下拉，含“全部”选项；选择后按完整名称精确匹配，其他输入条件仍模糊匹配，多个条件 AND 组合。
